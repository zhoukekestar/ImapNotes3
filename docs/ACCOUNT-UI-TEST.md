# 登录和账号界面验证

版本：1.4.8-microg.7（10414）
日期：2026-10-09
设备：Android 15 / API 35 模拟器，标准 microG 0.3.17；在原数据上覆盖安装，保留账号和笔记。

## 界面调整

参考 [Material 3](https://m3.material.io/foundations/) 的表单分组、按钮层级与设置页布局，保留笔记应用的暖色调。

- Google 入口直接打开账号选择；选择后显示账号信息，不再要求先勾选开关。可改用邮箱登录，再重新选择 Google。
- 邮箱登录与已有账号设置区分标题、说明和凭据提示；QQ / 163 自动配置及授权码帮助继续可用。
- 登录 / 保存、取消及即时 loading 位于固定底栏，长表单和软键盘不会挤走操作入口。
- 同步和服务器设置可展开、收起，编辑时显示当前文件夹和同步间隔。
- 移除账号与保存分开；增加确认弹窗，取消后账号保持。
- 列表页的账号切换和设置入口采用统一的图标、留白与卡片。

## 验证结果

- 62 项 JVM 测试通过；lint 0 错误。新增中文和英文文案，其他语言使用英文回退。
- 账号界面探针 10 项通过：QQ / 163 默认值、邮箱切换、自定义服务器及展开收起、即时 loading、防重复提交、错误恢复、重试、取消、移除确认取消、Google / 邮箱切换、Google loading 与取消。
- 标准 microG 的 7 项登录回归通过：已有账号、无保存密码、缓存令牌 IMAP 连接、刷新令牌 IMAP 连接、列表启动、页面关闭后的回调。
- 实际点击 Google 登录入口，选择已有 Google 账号并确认；返回后显示账号卡片、隐藏密码框，取消退出。
- 实际编辑 QQ / 163 已有账号，授权码留空后点击保存；均使用已保存的凭据完成邮箱连接并返回笔记列表。
- 检查浅色和深色模式；深色输入框使用明确的边界和聚焦颜色。
- 检查 1.3 倍字体与软键盘：字段可滚动，邮箱到密码的键盘焦点切换正常，固定主按钮可见且可操作。恢复字体和外观设置。

没有更改邮箱协议或笔记同步逻辑。本次沿用上一版已验证的 QQ / 163 / Gmail 同步行为；服务器测试详情见 [QQ 验证](QQ-LOGIN-TEST.md) 和 [163 验证](163-LOGIN-TEST.md)。界面截图留在本机测试缓存，不包含在公开发布资产中。
